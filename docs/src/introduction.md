# Better Car AI

A Cyberpunk 2077 (v2.5) mod that makes driving smarter: its own driving AI (Autodrive+), better routes to the map destination, calmer NPC traffic and tuning for the game's own autodrive.

{{#include ../../README.md:features}}

This book collects the user guide (from the repository's `README.md`) and the research notes behind the mod (`docs/RESEARCH.md`): how the game's traffic and autodrive work, what the native plugin found in memory, and what each version of Autodrive+ changed and measured.
